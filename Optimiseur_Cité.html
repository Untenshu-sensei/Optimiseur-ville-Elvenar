Bâtiment

📖 Notice & Mode d'emploi

🎯 Objectif : Cet outil vous permet de planifier et d'optimiser l'agencement de votre cité Elvenar sans toucher à votre vraie ville en jeu.

📥 Comment importer sa cité (via Idavis / ElvenAssist) ?

  1. Récupérer les données : Sur votre outil de gestion habituel (comme l'architecte ElvenStudio / Idavis ou ElvenAssist), exportez ou copiez le code source / texte JSON de votre ville.
  2. Ouvrir l'importateur : Cliquez sur le bouton 📋 Coller dans la barre d'outils en haut.
  3. Coller le texte : Collez l'intégralité du code ou des données de votre cité dans la zone de texte qui s'affiche.
  4. Valider : Cliquez sur ✅ Charger. Votre ville apparaîtra instantanément sur la grille !

⚡ Comment utiliser les fonctionnalités ?

  • ⚡ Optimiser : Lance le calculateur automatique pour réagencer la cité, réduire les rues et libérer de l'espace.
  • ✋ Déplacer : Cliquez-glissez n'importe quel bâtiment sur la grille pour l'ajuster manuellement.
  • 📦 Tout ranger : Envoie tous les bâtiments non verrouillés en réserve (à droite) pour repartir d'une grille propre.
  • 🔒 Verrouiller : Dans la fiche d'un bâtiment, cochez "Verrouiller" pour interdire à l'optimiseur de le bouger.

Scénarios d’implantation

Choisis une proposition pour l’afficher sur la carte. L’aperçu ne modifie pas ta sauvegarde. Seul le bouton « Appliquer » valide le remaniement ; « Fermer » restaure la cité telle qu’elle était avant le calcul. Les rues en stock sont automatiqument ramassées et réutilisées. Tous les scénarios garantissent une connexion à 100 % à l'HdV.
