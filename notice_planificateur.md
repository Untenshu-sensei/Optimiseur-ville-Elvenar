# 📖 Guide Complet & Détaillé — Planificateur de Cité Elvenar

Bienvenue dans ce guide d'utilisation du Planificateur de Cité. Cette notice a pour but de t'expliquer en détail le fonctionnement de chaque bouton et de t'aider à importer et manipuler le plan de ta cité sans aucune difficulté.

---

## 🗂️ 1. Boutons d'Importation et d'Exportation (Barre Supérieure)

Au sommet de l'interface du planificateur, tu trouveras les commandes principales pour charger ou sauvegarder ta ville.

### 📂 Le bouton "Fichier" (Importation JSON)
* **Format accepté :** Fichier d'extension `.json`.
* **Utilisation principale :** À utiliser si tu télécharges l'exportation de ta cité depuis le site **iDavis City Planner**.
* **Procédure :**
  1. Exporte et sauvegarde le fichier `.json` sur ton ordinateur depuis iDavis.
  2. Dans le planificateur, clique sur le bouton **📂 Fichier**.
  3. Sélectionne ton fichier `.json` dans tes dossiers : le planificateur reconstruit aussitôt ta cité.

### 📋 Le bouton "Coller" (Importation par Presse-Papier)
* **Format accepté :** Texte / Code brut d'exportation.
* **Utilisation principale :** À utiliser si tu récupères ton code d'exportation depuis le site **ElvenAssist**.
* **Procédure :**
  1. Copie le texte d'exportation fourni par ElvenAssist (`Ctrl + C` ou bouton *Copier*).
  2. Dans le planificateur, clique sur le bouton **📋 Coller**.
  3. Colle le texte dans la zone dédiée (`Ctrl + V`) puis valide pour charger ton village.

### 💾 Le bouton "Sauvegarder" / "Exporter"
* **Utilité :** Génère un fichier ou un code contenant toutes tes modifications actuelles.
* **Procédure :** Une fois que tu as fini de réorganiser tes bâtiments, clique sur ce bouton pour garder une copie de ton nouveau plan de cité.

---

## 🛠️ 2. Fonctionnement de la Grille et Reconnaissance des Bâtiments

Lors de l'importation, le planificateur positionne automatiquement l'ensemble de tes extensions et de tes bâtiments sur le terrain.

### 🤖 Reconnaissance automatique
* Tous les bâtiments déjà enregistrés dans la base de données de l'outil sont reconnus immédiatement (nom, catégorie, dimensions).

### 🔍 Gestion des nouveaux bâtiments ou inconnus
* Si un bâtiment n'est pas identifié automatiquement lors de l'importation :
  1. **Clique une seule fois** sur le bâtiment non reconnu sur la grille.
  2. Une fenêtre d'édition apparaît.
  3. Sélectionne ou saisis le nom et la catégorie du bâtiment pour l'attribuer définitivement.

---

## 🖱️ 3. Commandes de Manipulation sur la Grille

* **Déplacer un bâtiment :** Maintiens le clic gauche enfoncé sur un bâtiment et glisse-le vers l'emplacement souhaité.
* **Pivoter un bâtiment :** Utilise la commande de rotation (ou la touche associée) pour basculer les dimensions d'un bâtiment rectangulaire ($4 \times 3 \rightarrow 3 \times 4$).
* **Supprimer un élément :** Clique sur le bâtiment et sélectionne l'option de suppression pour libérer des cases sur la grille.

---

🔒 *Information de sécurité : Cet outil fonctionne exclusivement en local dans ton navigateur web. Aucune donnée n'est transmise vers un serveur distant et aucune installation n'est requise sur votre appareil.*
